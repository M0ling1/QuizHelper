# 答题助手 (QuizHelper)

悬浮球 → 读屏 → DeepSeek 作答 → 状态栏/气泡显示 → 自动点选项 → 自动点「下一题」。

## 安装

下载 [QuizHelper-1.0-arm64.apk](https://github.com/M0ling1/QuizHelper/releases/download/v1.0/QuizHelper-1.0-arm64.apk)（arm64-v8a，18 MB），拷进手机点击安装（需要允许「安装未知应用」）。

或者连上电脑用 adb：

```bash
adb install -r QuizHelper-1.0-arm64.apk
```

## 首次配置

打开 App → 点「权限/授权」，把这几项依次打开：

| 项目 | 说明 |
|---|---|
| ① 悬浮窗权限 | **必须**。不开就没有悬浮球 |
| ② 通知权限 | Android 13+ 必须，否则状态栏看不到答案 |
| ③ 无障碍服务 | **自动点击的核心**。设置 → 无障碍 → 已安装的服务 → 答题助手 → 开 |
| ④ Shizuku 授权 | 可选但强烈建议。免 root 拿到 shell 权限，能截图 + `input tap` 点击 |
| ⑤ 屏幕录制授权 | 不用 Shizuku 时的截图方式 |
| ⑥ 电池优化白名单 | 建议开，否则部分国产 ROM 会在后台杀掉服务 |

> 部分国产 ROM 额外要做的：设置 → 应用管理 → 答题助手 → 耗电管理 → 允许完全后台行为；
> 以及最近任务里给答题助手下拉「锁定」。

然后进「设置」填 **API Key**（`sk-...`），保存。

回到主页点 **启动悬浮窗**。屏幕上会出现一个蓝色的「答」字球，可以拖动。

## 怎么用

1. 打开题库 App，停在题目页
2. 点一下悬浮球
3. 等 1~3 秒，屏幕上半部分弹出气泡显示答案 + 解析，状态栏同时有一条通知（默认 8 秒）
4. 开了「自动点击答案」会自己点 A / C（多选按顺序点）
5. 开了「自动点下一题」，等 n 秒后自动找「下一题」按钮点掉

悬浮球是圆的、半透明水晶质感：拖动松手后吸附到最近的边缘；静止 n 秒（默认 10 秒）后自动收起。

**四种颜色 = 四种状态**：

| 球 | 含义 | 短按一下 | 长按 |
|---|---|---|---|
| 🟢 绿「待」 | 待启动（刚启动 / 刚停） | **开始答题**（立刻读当前屏） | 暂停 → 灰 |
| 🔵 蓝「答」 | 正在答 | 重读当前屏幕 | 暂停 → 灰 |
| ⚪ 灰「停」 | 你按停的 | 先回到绿的「待启动」 | — |
| 🔴 红 | 出错停下（读不到屏 / 大模型失败 / 解析不出） | 先回到绿的「待启动」 | — |

点「启动悬浮窗」不会马上开答：球先停在绿色的「待启动」上，切到题目页再点一下，它才开始读屏。长按只暂停，不会切走你正在看的页面。

## 看日志

主页列表就是问答日志：时间、答案、来源、耗时、解析。点任意一条看完整题目原文，可以复制。

标题右边的 **「全屏看」** 是放大版阅读器，可以切换「问答日志 / 运行日志」。卡住、没反应时先看运行日志。

无障碍被系统关掉时，屏幕上会自动弹一张引导卡，点「去打开设置」把开关打开即可。

## 设置项

- **取词方式**：默认「视觉优先」——先把整屏截图发给视觉模型，读不到自动改用无障碍文本。也可以选自动、仅无障碍文本、仅本地 OCR、仅视觉大模型。
- **截图方式**：自动（Shizuku 优先）/ 仅 Shizuku / 仅屏幕录制。
- **顶部 / 底部裁剪 %**：裁掉状态栏和标题栏，一般顶部填 6~10。
- **选项标签**：默认 `A,B,C,D,E,F,G,H`。用 `①②③④` 或 `甲乙丙丁` 的题库在这里改。
- **下一题关键词**：默认 `下一题,下一页,下一节,下一关,下一步,继续,确认,提交,Next,...`，按包含匹配。
- **自动点下一题 + 下一题延迟**：多选或需要确认的题，延迟给 2~3 秒。
- **悬浮球不透明度**：可调 80~100。低于 80 系统会判定为不可信窗口，触摸事件可能不派发给它。
- **自动收起等待**：默认 10 秒，填 0 = 永不收起。
- **自检**：一次检查无障碍、读屏、视觉模型、选项定位、下一题按钮和 API 是否可用。

## 常见问题

**截图全黑 / 提示 FLAG_SECURE**

目标 App 禁止截屏（银行、考试、部分题库）。默认的「视觉优先」会自动改读无障碍文本，不影响使用；想彻底不弹录制授权框，把取词方式改成「仅无障碍文本」。

**屏幕上没读到文字**

先看自检里的「读到的文字」。空的话检查：无障碍开没开、权限给没给、目标 App 是不是 WebView/Unity 画的（改成本地 OCR 或视觉大模型）、截图是不是黑的。

**能出答案但不自动点**

无障碍没开；或者选项标签不匹配（自检里看「选项 A：已定位 / 未找到」）；或者按钮 `clickable=false`，需要 Shizuku 才能按坐标点。

**自动点「下一题」没反应**

把按钮上的实际文字加进「下一题关键词」。

**悬浮球过一段时间消失**

电池优化白名单、允许完全后台、最近任务锁定，三件套都做。

**答案不对**

调小「顶部裁剪」避免题目被裁掉；模型换成 `deepseek-reasoner` 更准但更慢；系统提示词可以自己改，要求模型返回 `{"answer":"AC","explanation":"..."}`。
